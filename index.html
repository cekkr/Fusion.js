Welcome in ColibriJS project

First primitive version:

ColibrìJS Client

At this time the client can estabilish a connection with server, get a session id and request valued variables e objects as reference. Can get and set properties of .NET objects and call his method. A base management of exceptions is present.

For execute test use npm "test" (for windows) or "testlinux" scripts

Colibrì.NET Server

At this time server supports a primitive version of a session pool managment (with classes SessionManager and SessionToken). It can establish a connection with ColibriJS clients and passing object as value or reference (saved in ObjectsPool). For object handling have the following operations: get: for get a generic member of the object (a Property, Field, Method) as value, reference or function. set: for set a Property or Field member methodExec: for invoke a Method member

At this time server can pass an object reference to client but not viceversa. Client can send to server only string at this time. Colibrì.NET GitHub page can be found here: https://github.com/cekkr/Colibri.NET
